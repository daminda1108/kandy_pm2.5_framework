## Conclusions {#b-conclusions-list}

The conclusions are given against the objectives set out in {{ref:b-aims}}.

1. **Withholding an observation can be made an exact measurement.** A decomposition that fixes the
   city-wide mean and declares, tier by tier, which streams each part may use returns the simpler
   tier exactly when a stream is removed, so the difference between tiers is the value of the data.
2. **The value of each stream is measurable, and it is not what intuition supplies.** Free
   geography is worth {{claim:step.geography}} per cent, comparable to a first local instrument;
   one local station buys {{claim:stn.one_gain}} per cent and further stations almost nothing; a
   regional background series is the largest pooled gain at {{claim:step.bud2_bud3}} per cent.
3. **The ordering is conditional and the conditions are measured.** It reverses in the deep
   tropics, reverses again for exceedance detection, and a covariate trained on the same monitors
   can make the tropical reversal indistinguishable from zero. The redundancy of further stations survives every check.
4. **Within-city spatial information is a measured limit.** No model family built on freely
   available covariates beats the best single raster by more than the detection limit of
   {{claim:phase1.min_detectable}} in rank correlation, fixed before the test was run.
5. **For Kandy the first observation to obtain is local**, and reference grade because that would
   also settle the absolute level; for detecting episodes it is a regional background series.
