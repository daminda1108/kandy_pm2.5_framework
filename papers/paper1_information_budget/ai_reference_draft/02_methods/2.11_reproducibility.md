## 2.11 Reproducibility

**Code and data.** All analysis code is available at ⟨repository⟩ (archived at ⟨Zenodo DOI⟩). The
estimator used for the confirmation was frozen at commit `ba0da66`; a manifest records the SHA-256
hash of every file in its analysis path, and the confirmation panel and its member stations are
fixed by hash as well. Every input is public: PM2.5 from the OpenAQ archive and the CNEMC network
archive, drivers from ERA5 and ERA5-Land, aerosol optical depth from MODIS MAIAC and static
geography from GHSL, MODIS, Hansen, JRC, VIIRS, ESA WorldCover and OpenStreetMap, all retrieved
through Google Earth Engine or the providers' archives [@OpenAQ; @CNEMC; @Hersbach2020; @MunozSabater2021; @Lyapustin2018; @SchiavinaSMOD2023; @Didan2021; @Hansen2013; @Pekel2016; @Schiavina2023; @Pesaresi2023; @Elvidge2017; @Zanaga2022; @OpenStreetMap; @Gorelick2017].

**Checks that run with the analysis.** Each data frame is validated before fitting: unique
city-day keys, physical ranges for every driver, static features constant within a city, and
coverage of every admitted stream (Section 2.4). Every scoring loop records each city it skips and
why. Every analysis builds its frame through one shared function, so an exclusion made for one analysis cannot silently miss another. A regression test asserts that the redesigned estimator, run at the original settings,
reproduces the original ladder to within 10⁻⁹ for every city and rung, so every difference between
the two versions is attributable to a deliberate change.

**Randomness.** Station splits, learner seeds, bootstrap draws and panel selection all use fixed
seeds recorded in the code. Headline effects are medians over 21 station splits and 5 learner seeds,
so they do not depend on any single draw (Section 2.3.5).

**A limit on bit-for-bit reproduction.** One estimator family in the spatial learning curve
(TabPFN) gives identical results when re-run on the same machine but not across machines: 80 tasks
re-scored on a second computer matched in 1 (median difference in rank correlation 0.012, maximum
0.29), for reasons we could not isolate (numerical library or processor instruction set). All cities
were therefore scored in a single computing environment, and the registered amendment's claim of
reproducibility "on any machine" is corrected here (deviation D-8, Section 2.10).

**Two data defects found and corrected during the study.** A chunking error in the driver retrieval
had silently omitted the first and last partial quarter of every city's record (about 5% of
city-days), and one city had been fitted with missing geography in three analyses. Both were fixed
in the code that produces the data, all affected results were re-derived, and both are recorded in
the analysis ledger [F.113, F.115, F.116].
