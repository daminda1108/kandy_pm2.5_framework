## 4.3 What the confirmation changed, and why the design mattered

Three results changed between the discovery panel and the confirmation, and each change was one the
design was built to catch.

The first local stations were worth less than discovery suggested: 8.5 % against 21.8 %. The
discovery panel had been drawn to give each climate band equal weight, so it held 13 deep-tropical
cities in 46, where the first stations gain most. The confirmation panel reflects the population of
dense public networks, which is 70 % temperate. The confirmed number is the one that describes that
population. The discovery number described our sampling scheme as much as the world.

The ordering between a background series and the first local stations, which discovery could not
resolve on the ordinary day (+4.8 [−23.6, +52.1]), was resolved on confirmation (+24.6 [4.1, 47.8]).
We had registered this test as two-sided because discovery gave no direction. Had we instead read the
discovery medians, the background's gain of 34.4 % against the stations' 21.8 %, we would have claimed
the ordering before we had evidence for it. That comparison was a difference of medians, which Section
3.5 shows can point the wrong way.

The deep-tropical inversion, the result that first motivated much of this work, did not survive as
a finding. An earlier estimate put local stations at 4.2 times the value of a background in the deep
tropics, with an interval excluding zero. It came from one random split of each city's stations and
one learner seed. Averaged over 21 splits and five seeds, the interval crossed zero [F.115, F.116]. The
confirmation then could not test it at all. It is now a hypothesis, with a registered test waiting for
data that does not yet exist.

The fourth correction came after the confirmation, and none of those safeguards could have caught it.
The ordering the confirmation resolved compares two rungs that use their stations differently: the first
local stations only recalibrate the free estimate, the background is read on the day. Once every stream
was used the same way, the ordering vanished (−0.22 [−0.60, +0.04]) and every kind of station was worth
about the same, close to 58 % (Section 3.1.8). The registered test was run exactly as written, behind a
parity gate; it was the comparison written into the registration that did not compare like with like.
Registration fixes how a test is run. It does not check what the test means, and a design that
treats its arms asymmetrically should be expected to find an ordering.

Three design choices made the first three corrections possible, and we recommend them for any study of
this kind, together with a fourth: build every arm of a comparison the same way, and check that it is
built the same way, before registering it. Every effect was averaged over many random splits and learner seeds before it was bootstrapped,
because a single draw is not a result. Every comparison between observations was paired within city.
And the estimator was frozen and registered before it met data it had not seen, so the confirmation
could disagree with discovery and be believed when it did.
